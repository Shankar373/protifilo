# BookEase Demo Checklist

Use this checklist before showing BookEase to a prospective client.

## Customer demo
- [ ] Start MongoDB
- [ ] Start Spring Boot API
- [ ] Start React frontend
- [ ] Open landing page
- [ ] Choose a service
- [ ] Submit a valid booking
- [ ] Confirm success message
- [ ] Submit the same date/time again and confirm duplicate protection

## Business demo
- [ ] Open dashboard
- [ ] Confirm booking appears
- [ ] Confirm booking status
- [ ] Cancel a booking
- [ ] Refresh and verify persisted data

## Portfolio presentation
- [ ] Add live frontend URL when deployed
- [ ] Add API URL when deployed
- [ ] Add 4–6 screenshots
- [ ] Add a short demo video/GIF
- [ ] Link CASE-STUDY.md from the root README
- [ ] Clearly label the project as a self-created portfolio demonstration

## Production readiness before selling it as a client product
- [ ] Authentication
- [ ] Role-based authorization
- [ ] Rate limiting
- [ ] Centralized exception handling
- [ ] Automated integration tests
- [ ] Secure secrets/configuration
- [ ] Production MongoDB
- [ ] HTTPS deployment
- [ ] Logging/monitoring
- [ ] Backup and recovery plan
