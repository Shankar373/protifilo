# BookEase — Service Booking Platform

A portfolio-grade booking application concept for small service businesses such as clinics, salons, consultants, repair services and coaching centers.

## Product goal
Customers can discover services and request time slots; business owners can manage services, availability, bookings and customers.

## Planned stack
- React
- Java 21 + Spring Boot
- MongoDB
- REST APIs
- JWT authentication
- Docker

## Customer workflow
Register → browse services → choose date/time → book → view/cancel booking.

## Business workflow
Login → dashboard → services → availability → bookings → customers.

## Engineering scope
DTOs, validation, global exception handling, role-based authorization, MongoDB indexes, environment configuration, tests and Docker-ready deployment.

> Portfolio demonstration: this is not presented as completed client work.
