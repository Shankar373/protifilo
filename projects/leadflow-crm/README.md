# LeadFlow CRM

LeadFlow is a self-created portfolio demonstration of a lightweight CRM for small businesses and service companies.

## Problem
Small teams often manage enquiries in spreadsheets and lose track of follow-ups, sales stages and potential customers.

## Demonstrated workflow

1. Capture a lead
2. Qualify the opportunity
3. Move it to proposal
4. Track won/lost outcomes
5. Review pipeline health

## Demo features

- Search leads
- Add a demo lead
- Move leads through sales stages
- Pipeline statistics
- Qualification/proposal/won counts
- Local browser persistence with `localStorage`
- Responsive dashboard
- Mobile-friendly table and controls

## Production architecture

A production version can use React or Angular + Spring Boot REST API + MongoDB + JWT authentication + role-based access + email/WhatsApp integrations + cloud deployment.

## Authenticity

This is a **self-created portfolio project**, not a client project. Demo data is illustrative and is not presented as real business results.
